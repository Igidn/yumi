# Yumi Tech Stack

## App Shell
- **Electron 33+** — all platform APIs, native menus, file dialogs, IPC
- **electron-builder** — packaging (macOS DMG, code signing, auto-update later)

## Renderer
- **React 19** — component model, hooks, concurrent features
- **TypeScript 5.7+** — strict mode everywhere
- **Vite 6** — renderer bundling, HMR, `@tailwindcss/vite` plugin
- **Tailwind CSS v4** — utility-first CSS, CSS-based config (no JS config file needed)

## Database
- **sql.js** (npm: `sql.js`) — SQLite compiled to WASM, zero native deps. Works on any Node version.
- **Drizzle ORM** — TypeScript schema definitions, query builder, migrations (via `drizzle-kit`)

### Why sql.js, not better-sqlite3
`better-sqlite3` is a native C++ addon. It fails to build on Node 26 because V8 removed `GetPrototype()`, `GetIsolate()`, and `This()` APIs that the addon's source calls. Electron ships its own Node, but `npm install` builds against system Node.

`sql.js` is the identical SQLite engine compiled to WASM. It loads as a JS module — zero native compilation. Performance is identical for an ebook reader workload (reads/writes are measured in microseconds either way). Drizzle's `drizzle-orm/sql-js` driver wraps it cleanly.

### Database setup pattern
```ts
// src/main/database.ts
import initSqlJs from "sql.js";
import { drizzle } from "drizzle-orm/sql-js";

const SQL = await initSqlJs();
const sql = new SQL.Database();
const db = drizzle(sql, { schema });

// Persistence: call sql.export() and write the Uint8Array to disk
// after mutations. For v1, write on every mutation (simple).
```

## State Management
- **Zustand 5** — minimal, no provider wrappers, selector-based re-renders, works across Electron windows via IPC if needed later

## Drawing
- **Excalidraw** (npm: `@excalidraw/excalidraw`) — React component, fully-featured whiteboard. Renders as a transparent overlay on text content.

## Math
- **KaTeX** (npm: `katex`) — LaTeX rendering for equations from OCR-processed textbooks

## App Settings
- **electron-store** — JSON key-value store on disk, simpler than SQLite for preferences (window bounds, last-opened book, theme)

## Project Structure
```
yumi/
├── package.json
├── tsconfig.json              # base config
├── tsconfig.main.json         # extends base, targets CommonJS (Electron main)
├── tsconfig.renderer.json     # extends base, targets ESM + Vite (renderer)
├── vite.config.ts             # Vite config with React + Tailwind plugins
├── drizzle.config.ts          # drizzle-kit config pointing at drizzle/
├── electron-builder.yml       # packaging config
├── drizzle/
│   ├── schema.ts              # Drizzle table definitions
│   └── migrations/            # auto-generated by drizzle-kit
└── src/
    ├── main/
    │   ├── index.ts           # Electron main process entry
    │   ├── preload.ts         # contextBridge API for renderer
    │   └── database.ts        # sql.js + Drizzle init
    ├── renderer/
    │   ├── index.html         # HTML shell
    │   ├── main.tsx           # React mount point
    │   ├── App.tsx            # root component
    │   └── globals.css        # @import "tailwindcss"
    └── shared/
        └── types.ts           # IPC channel types, shared interfaces
```

## Build Scripts (package.json)
```jsonc
{
  "scripts": {
    "dev":         "concurrently \"npm run dev:renderer\" \"npm run dev:main\"",
    "dev:renderer":"vite",
    "dev:main":    "tsc -p tsconfig.main.json && electron .",
    "build":       "vite build && tsc -p tsconfig.main.json",
    "build:renderer": "vite build",
    "build:main":  "tsc -p tsconfig.main.json",
    "pack":        "electron-builder --dir",
    "dist":        "electron-builder",
    "db:generate": "drizzle-kit generate",
    "db:migrate":  "drizzle-kit migrate"
  }
}
```

## What's Already Done
The scaffolding files already exist in this repo (all the `src/`, `drizzle/`, config files). The package.json is written. `npm install` was failing because of the `better-sqlite3` native build issue — the fix is already applied (switched to `sql.js` in package.json and `database.ts`).

## To Get Running
```sh
cd ~/Desktop/Projects/dev/yumi
mv node_modules ~/.Trash/yumi-node-modules   # clean the failed install
mv package-lock.json ~/.Trash/yumi-package-lock  # clean stale lockfile
npm install                                   # fresh install (sql.js has no native deps)
npm run dev                                   # starts Vite + Electron
```
